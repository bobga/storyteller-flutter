# Storyteller

A modern social media application built with Flutter and Laravel, inspired by Instagram. Share your moments through photos and videos with a beautiful, intuitive interface.

## Features

- 📸 Photo and video sharing
- 🎥 Story creation and viewing
- 👥 Social interactions (likes, comments, follows)
- 🌐 Multi-language support (English, Spanish, French, Italian, Russian, Chinese)
- 📱 Cross-platform (iOS and Android)
- 🔒 Secure authentication
- 🎨 Photo filters and editing
- 📍 Location sharing
- 🔔 Real-time notifications

## Getting Started

### Prerequisites

- Flutter SDK (>=2.7.0)
- Dart SDK
- Android Studio / Xcode
- Laravel backend setup

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/storyteller-flutter.git
```

2. Navigate to the Flutter project directory:
```bash
cd storyteller-flutter/flutter
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```

## Tech Stack

- **Frontend**: Flutter
- **Backend**: Laravel
- **State Management**: Provider
- **Network**: Dio
- **Storage**: Flutter Secure Storage
- **Media Handling**: Camera, Image Picker, Video Player
- **UI Components**: Various Flutter packages for enhanced UI/UX
